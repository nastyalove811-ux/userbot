О проекте

info

Этот интерфейс управляет Web API для Userbot, включая добавление аккаунтов, переключение состояния и просмотр логов.

Следующие функции в проекте намеренно не добавляются, чтобы избежать автоматизации агрессивных действий:

  • массовая рассылка (spam / cspam / wspam / delayspam)
  • авто-троллинг по триггеру (Toxic)
  • скрытый перехват чужих правок/удалений/файлов (StealMan)
  • массовые упоминания (TagAll)
  • автореакции на конкретных пользователей (ZaebReactions)

Эти ограничения сделаны для безопасной работы проекта.
